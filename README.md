# Nexus Docs

**Nexus Docs** là trình soạn thảo văn bản miễn phí, mã nguồn mở, thuộc bộ ứng dụng văn phòng
**NexusOffices** của **Sonnytech**. Mở và lưu tệp Word (.docx, .doc), ODT, RTF, HTML, Markdown,
xuất PDF; giao diện tiếng Việt; chạy trên Windows, macOS, Linux và trình duyệt.

Nexus Docs được phát triển dựa trên WordCraft của ArtCraft (MIT/Apache-2.0).

  liệt kê trong [`NOTICE`](NOTICE) và [`ATTRIBUTION.md`](ATTRIBUTION.md).

## English

**Nexus Docs** is a free, open-source word processor, part of the **NexusOffices** office suite by
**Sonnytech**. It opens and saves Word files (.docx, .doc), ODT, RTF, HTML and Markdown, exports PDF,
and runs on Windows, macOS, Linux and in the browser.

Nexus Docs is developed from WordCraft by ArtCraft (MIT/Apache-2.0).
